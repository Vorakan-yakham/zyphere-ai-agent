# Zyphere - Meta AI Sidebar + Google Login

## Features
- Sidebar: Tab hides to 64px icon rail, Logo click toggles 280px <-> 64px
- Icons animate on hover (scale 1.15, lift, logo spins)
- Login: Continue with Google / Email, switch account, Whisp default
- 4 Brains: 1 Grok (xai-), 2 Gemini (AIza), 3 OpenRouter (sk-or-), 4 Hugging Face (hf_)

## Upload to GitHub Pages
Upload index.html + app.py + requirements.txt to Vorakan-yakham/zyphere-ai-agent, Replace old files, wait 1-2 min, Ctrl+Shift+R

## After upload
Click gear (⚙) bottom-left > API Key > Paste key > Save (button shows ✓ บันทึกแล้ว)
Keys stay in browser only, never uploaded to GitHub.
