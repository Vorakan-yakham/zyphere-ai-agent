# Zyphere COMPLETE17 — AI Agent (ไซเฟอร์)

Zyphere เป็นผู้ช่วย AI ภาษาไทย/อังกฤษที่ทำงานผ่านเว็บ โฟกัสที่ “คุยโต้ตอบเป็นธรรมชาติ ทำงานตามคำสั่ง และสืบค้น/จดจำข้อมูลได้ด้วยตนเอง” มากขึ้น โดยพัฒนาต่อจาก Zyphere COMPLETE16

## ความสามารถหลัก
- **สนทนาแบบเป็นธรรมชาติ**: บุคลิกคงเส้นคงวา เข้าใจบริบทต่อเนื่อง ตอบกระชับเหมือนคุยกับคน
- **Agent ใช้เครื่องมือเอง**: วางแผนและเรียกเครื่องมือเพื่อทำงาน เช่น ค้นเว็บ อ่านเนื้อหาจากหน้าเว็บ ดูเวลา/อากาศ สร้างภาพ และจัดการความจำ
- **สืบค้นข้อมูลด้วยตนเอง**: ค้นหาจากเว็บและเปิดอ่านแหล่งข้อมูลผ่าน backend (`/api/search`, `/api/fetch`) แล้วสรุปตอบ พร้อมอ้างอิงแหล่งที่ใช้
- **ความจำและการเรียนรู้สะสม (self-improvement แบบสะสมความรู้)**: บันทึกโปรไฟล์ผู้ใช้ ข้อเท็จจริง ความชอบ และ “บทเรียน/โน้ต” ที่ได้จากการทำงานลงหน่วยความจำถาวร (`data/memory.json`) เพื่อนำมาใช้ในครั้งถัดไปโดยอัตโนมัติ — ไม่ต้องสอนหรืออัปเดตซ้ำทุกครั้ง
- **ความสามารถเดิม**: แนบ/อ่านไฟล์หลายชนิด (รวม .zip/.docx/.xlsx/.pptx/.pdf/โค้ด/รูป/เสียง), วาด/แต่งภาพ, โหมดเสียง, โหมดเขียนโค้ด, ประวัติแชท

## ข้อจำกัดที่สำคัญ (โปร่งใส)
- “พัฒนาตนเอง” ในที่นี้หมายถึง **การสะสมความจำ/บทเรียนจากการใช้งาน** ไม่ใช่การแก้ไขโค้ดหรือเปลี่ยนน้ำหนักโมเดลของตัวเองโดยอัตโนมัติ (การอัปเกรดตัวระบบยังต้องปรับโค้ด/โมเดลโดยผู้พัฒนา)
- การ “ทำอะไรที่สั่งทุกอย่าง” และ “คุมเครื่องจักร/อุปกรณ์” ถูกจำกัดด้วยสิทธิ์ เครื่องมือที่เชื่อมต่อ และสภาพแวดล้อม: เวอร์ชันนี้เน้นงานข้อมูล/เว็บ/ไฟล์/สนทนาและโครง agent ที่ต่อยอดได้ หากต้องคุมอุปกรณ์จริงให้เชื่อมผ่านเครื่องมือ/บริการภายนอก (เช่น Home Assistant, MQTT, สคริปต์ระบบ) และควรมีการยืนยันก่อนทำงานที่มีผลกระทบ
- การสืบค้นเว็บและความจำถาวรทำงานเต็มที่เมื่อรันผ่านเซิร์ฟเวอร์ (`python app.py`) หากเปิด `index.html` ตรง ๆ บางฟังก์ชัน (ค้นเว็บ/อ่านเว็บ/บันทึกความจำถาวร) อาจใช้ไม่ได้เพราะข้อจำกัดของเบราว์เซอร์

## การติดตั้งและใช้งาน (แนะนำ)
ต้องมี Python 3.9+

```bash
pip install -r requirements.txt
python app.py
```

จากนั้นเปิดเบราว์เซอร์ที่ `http://localhost:8000`

- กด **ตั้งค่า** แล้วใส่คีย์ผู้ให้บริการอย่างน้อย 1 รายการ (Groq / Gemini / OpenRouter / Hugging Face)
- เปิด **ค้นเว็บ/โหมด Agent** ในหน้าตั้งค่าเพื่อให้ไซเฟอร์สืบค้นและใช้เครื่องมือได้เอง
- ข้อมูลความจำสะสมจะถูกเก็บที่ `data/memory.json` (ลบไฟล์นี้หากต้องการรีเซ็ตความจำ)

## โครงสร้างไฟล์
- `index.html` — ส่วนติดต่อผู้ใช้และลูป agent ฝั่งเบราว์เซอร์
- `app.py` — เซิร์ฟเวอร์โลคัล: เสิร์ฟหน้าเว็บ, TTS, ค้นเว็บ, ดึงเนื้อหาเว็บ, และจัดเก็บความจำถาวร
- `data/memory.json` — ความจำสะสม (สร้างอัตโนมัติเมื่อใช้งาน)
- `libs/` — ไลบรารีสำหรับอ่านไฟล์ฝั่งเบราว์เซอร์
- `requirements.txt` — รายการแพ็กเกจ Python

## เคล็ดลับการใช้งาน
- พูดคุยต่อเนื่องได้ตามปกติ ไซเฟอร์จะดึงความจำที่เกี่ยวข้องมาใช้เอง
- สั่งให้ “ช่วยจำว่า...” หรือให้ข้อเท็จจริงสำคัญเกี่ยวกับคุณ/งาน ไซเฟอร์จะบันทึกไว้ใช้ครั้งหน้า
- สั่งให้ค้นข้อมูลปัจจุบัน/เปรียบเทียบ/หาคำตอบจากหลายแหล่ง ระบบจะค้นและอ่านเว็บให้เองเมื่อเปิดโหมด Agent
- งานที่มีผลกระทบจริง (ลบ/แก้ไข/สั่งงานภายนอก) ควรตรวจทานก่อนเสมอ
