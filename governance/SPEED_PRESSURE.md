# ประกาศถึงพนักงานทุกแผนก (จากเจ้าของ)

**ยิ่งทำงานช้า ยิ่งได้โจทย์เพิ่ม — ระบบจะเติมงานให้ทุกแผนกที่เกินเวลา**

ถ้า pulse ใดใช้เวลา >60 วิ หรือมีเป้าไม่ผ่าน → เพิ่มโจทย์ใหม่เข้า board ทันที

## โจทย์ที่เพิ่มรอบนี้

- **3D realtime walkthrough → วิดีโอ** — จากงานก่อนหน้า ให้ทำ flow เดินได้แบบ realtime แล้วอัดเป็นวิดีโอ · ผู้รับผิดชอบ: วิศวกรสื่อ + วิศวกรภาพ (โมดูล `walkthrough_3d`)
- **ลดเวลา visual production ให้ <60s/รอบ** — ปัจจุบัน 33.6s — ต้องรักษาและลดต่อ · ผู้รับผิดชอบ: วิศวกรอัตโนมัติ (โมดูล `visual_production`)
