# คำสั่งประจำการให้ทุกฝ่าย (ไม่ต้องรอเจ้าของ)

สถานะ: **ทำงานต่อเนื่องแม้เจ้าของปิดเครื่อง** — GitHub Actions `autonomy.yml` รันทุก 30 นาที

## หลักการที่ทุกฝ่ายต้องยึด
1. ไม่รอคำสั่ง — วัดผลเอง หาจุดอ่อนเอง แก้เอง วัดใหม่ จำลงสมอง
2. ไม่ลบของที่ผ่าน QA แล้ว — แก้เฉพาะที่หลักฐานบอกว่าพัง
3. ไม่ claims ว่าเทียบเท่าใคร — รายงานเฉพาะตัวเลขที่วัดได้
4. ไม่พึ่ง API ภายนอกเป็นแหล่งความรู้หลัก — ใช้ `own_brain` + ความรู้ที่เก็บในเครื่อง
5. ทุกการแก้ต้องมีหลักฐาน: ไฟล์/endpoint/test/metric

## สายงานที่ต้องทำงานต่อ
| ฝ่าย | งานต่อเนื่อง | วัดผลด้วย |
|---|---|---|
| วิชาการ / โลก | `knowledge_engine.run()` เรียนรู้ทุกแขนงจาก 4,225 สาขา | จำ topics/facts เพิ่มขึ้น |
| สาขาใหม่ | `discipline_lab.propose()` เชื่อมความรู้จริงเป็นศาสตร์ใหม่ | จำ proposal + แหล่งอ้างอิง |
| สมอง Zyphere | `own_brain.grow()` หาจุดอ่อน → แก้ → จำใหม่ | growth_round + actions |
| กราฟิก | `advanced_filters` + `image_quality_loop` | sharpness before/after |
| วิดีโอ | `media_twin_track` คู่ขนานกับภาพ | MP4 + audio stream + SRT |
| หนังสือ | `ebook_design_team` + `ebook_editor_gate` | 4,000+ คำ, ภาษาไทย, ผ่าน gate |
| หัวหน้าฝ่าย/แผนก | `nudge_lazy.run()` ตรวจ output จริง | idle list ต้องว่าง |
| QA | `qa_audit_team.run()` ตรวจทุกด้าน | KEEP เพิ่ม / FIX ลด |
| self-coder | patch เฉพาะจุดที่ QA ชี้ | test ผ่าน + push จริง |

## คำสั่งถึงทุกฝ่ายโดยไม่มีข้อยกเว้น
"ถ้ายังพัฒนาศาสตร์ใหม่ไม่ได้ อย่าหยุด — กระตุ้นกันเองตลอดเวลา ทั้งตอนปิดเครื่องและเปิดเครื่อง"

หมายเหตุเพิ่มเติม: คำสั่งนี้ใช้กับ **ทุกฝ่าย** — วิชาการ ภาษา กราฟิก วิดีโอ หนังสือ การตลาด ขาย ปฏิบัติการ ความปลอดภัย QA สมอง Zyphere และ self-coder ทุกหน่วยต้องกระตุ้นกันเองต่อเนื่องแม้เจ้าของปิดเครื่อง

## มติสภาล่าสุด (เขียนโดยระบบ ไม่ต้องรอเจ้าของ)
- สร้าง STORE_V2.html ใหม่: hero ชัด, การ์ดสินค้า, CTA, QR, ช่องทางรายได้ 6 ช่องทาง
- ตั้งราคาทุกเล่มด้วย market_price + ความยาวจริง เปลี่ยนสถานะเป็น review จนกว่า QA จะผ่าน
- ปกใหม่ต้องสร้างจากเนื้อหาจริง (motif ตามหัวข้อ) + typography ใหม่ ไม่ใช้ภาพเก่าซ้ำ
- เก็บ products/channels/qa/metrics ลง data/commerce.json เป็นแหล่งร่วมของทุกฝ่าย
- ระบบกระตุ้นตัวเองทุก 30 นาที: analyze → plan → code → QA → learn ไม่ต้องรอเจ้าของ
